# SQL - Joins & Relationships

This directory contains SQL exercises focused on table relationships and retrieving related data using SQL joins and subqueries.

## Topics

- Relational databases
- Primary keys and foreign keys
- Referential integrity
- One-to-one, one-to-many, and many-to-many relationships
- SQL joins (`INNER JOIN`, `LEFT JOIN`, and `CROSS JOIN`)
- Junction tables
- Handling `NULL` values
- Subqueries
- Aggregate functions
- Grouping and counting related records
- Filtering and sorting data

## Files and Description

| **File** | **Description** |
| -------- | --------------- |
| `1-books-with-authors.sql` | Retrieves books with their corresponding authors. |
| `2-authors-with-books.sql` | Lists all authors and their books, including authors without books. |
| `3-students-and-courses.sql` | Retrieves students and the courses they are enrolled in. |
| `4-courses-and-students.sql` | Lists all courses and their enrolled students, including courses without students. |
| `5-students-with-enrollments.sql` | Finds students who have at least one course enrollment using a subquery. |
| `6-courses-above-average.sql` | Finds courses with enrollment counts above the average. |
| `7-course-enrollment-count.sql` | Counts enrollments for each course, including courses with no enrollments. |
| `8-courses-and-instructors.sql` | Retrieves courses with their assigned instructors. |
| `9-instructors-and-courses.sql` | Lists all instructors and their courses, including instructors without assigned courses. |
| `10-students-and-registered-courses.sql` | Retrieves students and the courses they have registered for. |
| `11-course-registration-count.sql` | Counts registrations for each course, including courses with no registrations. |
| `12-students-with-registrations.sql` | Lists students who have registered for at least one course. |
| `13-courses-above-average-assignments.sql` | Finds courses with assignment counts above the average. |
| `14-courses-and-assignments.sql` | Lists courses and their assignments, including courses without assignments. |
| `15-instructors-with-active-courses.sql` | Lists instructors teaching courses with at least one registered student. |
