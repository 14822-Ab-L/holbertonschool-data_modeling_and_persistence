# Data Modeling & Persistence

This repository contains projects focused on relational databases, SQL data manipulation, and relationships between tables.

## Topics

- Relational databases
- Tables, rows, and columns
- SQL
- SQLite
- Creating tables
- CRUD operations
- Filtering and sorting data
- Aggregate functions
- Grouping data
- Data modeling
- Primary keys and foreign keys
- Referential integrity
- One-to-one, one-to-many, and many-to-many relationships
- SQL joins (`INNER JOIN`, `LEFT JOIN`, and `CROSS JOIN`)
- Junction tables and subqueries

## Directories

| **Directory** | **Description** |
| ------------- | --------------- |
| `sql_crud` | Introduces SQL queries for creating tables, inserting and retrieving data, filtering, updating, deleting, sorting, and summarizing book records. |
| `sql_join` | Explores table relationships and SQL joins to retrieve related data, handle unmatched records, and summarize relationships using subqueries and aggregate functions. |
